# 对话
## 指令
- 如果我的对话语句中出现要求写文档、生成文档等含义的字眼，需要根据我的需求创建对应的文件，文档录入到文件中。

# 项目结构
- 项目本身使用 docsify 实现，配置文件在 index.html
- 项目使用的 docsify 目录有两级，一级为 _navbar.md ，二级在每个模块下的 _sidebar.md 中，比方说 Go/Golang/_sidebar.mdGo/Golang/_sidebar.md
- 项目内所有目录配置映射的文件路径均为基于项目根目录的路径。比如 Go/Golang/基础/package.md

# 网站文章渲染排版
## 文章标题
- 一级标题仅文章标题可以使用，直接说明技术就好不需要过多的额外阐述
- 文章内可以出现二、三级标题，不要出现四级及以下标题。
## 内容
- 展示时的页面宽度可以容纳 80 个中文字符，要求文章所有模块的布局在这个宽度下文案、图、表格等元素都能展示的比较好看。
- 文档内部可以增加适当的分割、注解、引用等元素，使文档更具可读性，文章看起来更加好看。
## 重点
- 重点文案需要突出显示，使用 `entry`  或者 **etry**， 而不是 **`entry`**，**1`entry`**，**`entry`2** 这些情况。

# 技术知识文档要求
## 文本
- 内容丰富、要包含介绍、特性、实现原理、同类型实现对比等多个方面。
- 内容的逻辑性、准确性、可读性、完整性要达到最高标准。
## 图
- 使用 mermaid 图对类的关系、数据结构、算法流程、技术机构、业务架构、工作流程、数据流转等进行可视化展示。
- 一定要保证图可以正常渲染，标题可以放在图外边展示。
