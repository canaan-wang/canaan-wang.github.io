# 项目介绍
- 这是我的个人博客项目，使用了 docsify 框架，部署在 github pages 上。
- docsify 配置文件为 index.html
- 主页为 README.md

## 内部 markdown 文档
- 文档大多数为知识文档，达到可以在行业内进行分享的程度。

### 标题
- 目录标题全部为二级标题（二级标题下的内容为一个特定的能力模块）
- 目录标题不要增加和文章标题相同的内容。比如说文章标题为 Mysql ，目录里就不要出现 mysql 这个字段。
- 不使用三级及以下标题。

### 重点标记
- 重点要突出显示，使用 `entry`  或者 **etry** 
- 禁止混合使用，比如： **`entry`**，**1`entry`**，**`entry`2** 这些情况。

### mermaid 图
- mermaid 图需要查在文档中的不同位置，不要集中在一起。

### 文档格式要求：
- 模块间使用 分割线 分割模块
- 文章在网页上的渲染宽度可以放置 80 个中文字符，需要保证文章在渲染时不要太空。
- 文章不需要添加目录，目录在网站上会自动生成。

# 对话要求
- 我的对话一般都是要求帮我整理文档
- 整理文件内容指的意思是要对文档直接进行修改，不用发到对话框。
- 文件内容是对话形式的，我需要你帮我整理为知识文档形式，能够达到可分享的程度。
- 禁止增加原文档外的内容，但是可以调整语气，语法，格式。
- 要求文档整体格式优美，达到可以在行业分享的程度。
