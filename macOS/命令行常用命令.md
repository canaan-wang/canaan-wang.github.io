# macOS 命令行常用命令

本文收录 macOS 终端中常用的原生命令与实用技巧，帮助提升日常操作效率。

---

## 剪切板操作

macOS 内置了与系统剪切板交互的命令行工具，无需额外安装软件即可在终端与图形界面之间传递文本内容。

**`pbcopy` — 复制内容到剪切板**

`pbcopy` 从标准输入读取数据，并将其写入系统剪切板，之后可在任意应用中使用 `Command + V` 粘贴。

将文件内容复制到剪切板：

```bash
cat file.txt | pbcopy
```

将命令输出复制到剪切板：

```bash
ls -la | pbcopy
```

将字符串直接复制到剪切板：

```bash
echo "Hello World" | pbcopy
```

**`pbpaste` — 从剪切板粘贴内容**

`pbpaste` 将剪切板中的内容输出到标准输出，支持进一步管道处理。

将剪切板内容输出到终端：

```bash
pbpaste
```

将剪切板内容写入文件：

```bash
pbpaste > file.txt
```

结合管道进行过滤处理：

```bash
pbpaste | grep "keyword"
```

## 文件格式转换

**`pandoc` — 文档格式转换**

`pandoc` 是一款功能强大的文档格式转换工具，支持 Word、Markdown、HTML、PDF 等数十种格式之间的互转。

安装：

```bash
brew install pandoc
```

将 **Word 文档转换为 Markdown**：

```bash
pandoc input.docx -o output.md
```

保留图片并指定输出目录：

```bash
pandoc input.docx -o output.md --extract-media=./images
```

从 Markdown 生成 Word 文档：

```bash
pandoc input.md -o output.docx
```

常用参数说明：

- `-o`：指定输出文件
- `--extract-media`：提取嵌入的图片到指定目录
- `-t`：指定目标格式，如 `markdown`、`html`、`pdf`
- `-f`：指定源格式

## 文件与目录操作

macOS 基于 BSD，文件操作命令与 Linux 基本一致，部分命令带有 Darwin 特性。

**`open` — 使用默认程序打开文件或目录**

`open` 是 macOS 特有的命令，用于在图形界面中打开文件、目录或 URL。

打开当前目录：

```bash
open .
```

用默认应用打开文件：

```bash
open document.pdf
```

在 Finder 中定位并选中文件：

```bash
open -R file.txt
```

使用指定应用打开文件：

```bash
open -a Safari https://example.com
```

## 系统信息查看

**`sw_vers` — 查看系统版本信息**

```bash
sw_vers
```

输出示例：

```
ProductName:            macOS
ProductVersion:         14.5
BuildVersion:           23F79
```

**`system_profiler` — 查看硬件详细信息**

快速查看硬件概览：

```bash
system_profiler SPHardwareDataType
```

查看电池健康信息：

```bash
system_profiler SPPowerDataType | grep -A 5 "Battery Information"
```

## 网络相关

**`networksetup` — 网络配置管理**

查看当前 Wi-Fi 网络名称：

```bash
networksetup -getairportnetwork en0
```

查看所有网络服务列表：

```bash
networksetup -listallnetworkservices
```

**`lsof` — 查看端口占用**

查看指定端口的占用进程：

```bash
lsof -i :8080
```

## 端口占用查看（Linux 服务器）

在 Linux 服务器上排查端口冲突或服务监听状态时，以下命令更为常用。

**`ss` — 查看套接字统计信息**

`ss` 是 `netstat` 的现代替代命令，性能更高，信息更详尽。

查看所有监听的端口：

```bash
ss -tulpn
```

参数说明：

- `-t`：显示 TCP 端口
- `-u`：显示 UDP 端口
- `-l`：仅显示监听状态的端口
- `-p`：显示占用该端口的进程信息
- `-n`：以数字形式显示地址和端口，不进行域名解析

查看指定端口是否被监听：

```bash
ss -tulpn | grep :8080
```

**`netstat` — 网络连接与端口统计**

部分旧版系统仍使用 `netstat`，用法与 `ss` 类似。

查看所有监听端口及进程：

```bash
netstat -tulpn
```

查看指定端口：

```bash
netstat -tulpn | grep :8080
```

**`fuser` — 查找占用端口的进程 ID**

```bash
fuser 8080/tcp
```

结合 `kill` 强制释放端口（谨慎使用）：

```bash
kill -9 $(fuser 8080/tcp 2>/dev/null)
```

## 进程信息查看

获取进程 ID 后，可通过以下命令查看该进程的详细信息。

**`ps` — 查看进程快照**

查看指定进程的详细信息：

```bash
ps -p 1234 -f
```

查看更全面的信息，包括线程数、内存等：

```bash
ps -p 1234 -lf
```

查看进程启动的完整命令行：

```bash
ps -p 1234 -o pid,ppid,cmd,%mem,%cpu
```

**`/proc` 文件系统（Linux）**

Linux 将进程信息以文件形式暴露于 `/proc/<PID>/` 目录下，可直接读取。

查看进程状态：

```bash
cat /proc/1234/status
```

查看进程的完整启动命令：

```bash
cat /proc/1234/cmdline | tr '\0' ' '
```

查看进程的可执行文件路径：

```bash
ls -l /proc/1234/exe
```

查看进程的工作目录：

```bash
ls -l /proc/1234/cwd
```

**`pwdx` — 查看进程工作目录**

```bash
pwdx 1234
```

**`top` / `htop` — 实时监视进程**

仅监视指定进程：

```bash
top -p 1234
```

**`lsof` — 查看进程打开的文件**

```bash
lsof -p 1234
```

## 其他实用命令

**`say` — 语音朗读**

将文本转换为语音播报：

```bash
say "Hello, macOS"
```

指定语音和语速：

```bash
say -v Ting-Ting "你好，macOS" -r 200
```

**`caffeinate` — 防止系统休眠**

在长时间任务执行期间保持系统唤醒：

```bash
caffeinate -t 3600
```

参数 `-t` 后跟秒数，示例中表示保持唤醒 1 小时。

**`mdfind` — Spotlight 命令行搜索**

通过 Spotlight 索引快速搜索文件：

```bash
mdfind -name "filename"
```

在指定目录中搜索：

```bash
mdfind -onlyin ~/Documents "keyword"
```
